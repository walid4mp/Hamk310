# MizanPro V2

نظام محاسبة وإدارة أعمال سحابي عربي للشركات الصغيرة والمتوسطة والمحلات والسوبرماركت.

## الوحدات
- المؤسسة: بيانات الشركة والشعار، فروع متعددة، مستخدمون، أدوار وصلاحيات، Audit Log.
- المحاسبة: شجرة الحسابات، أصول/خصوم/حقوق ملكية/إيرادات/مصروفات، قيود مزدوجة، دفتر الأستاذ، ميزان المراجعة، فترات وإقفال، منع القيود غير المتوازنة.
- المبيعات والمشتريات: عملاء، موردون، منتجات، فواتير، مرتجعات، نقدي/آجل، خصومات، ضريبة، دفعات، وترحيل محاسبي تلقائي.
- المخزون: تصنيفات، وحدات، SKU/باركود، مستودعات، حركات، تحويلات، جرد، حد أدنى، وتحديث كميات ضمن transaction.
- الصندوق والبنوك: صناديق متعددة، حسابات بنكية، إيداع، سحب، تحويلات، حركات بنك، استيراد، ومطابقة.
- Dashboard: المبيعات، المشتريات، المصروفات، الأرباح، الذمم، المخزون، الصندوق والبنوك.
- التقارير: قائمة الدخل، الميزانية العمومية، التدفقات النقدية، ميزان المراجعة، دفتر الأستاذ، المبيعات، المشتريات، المخزون، العملاء، الموردون.
- اشتراكات: شهري / 6 أشهر / سنوي.

## التشغيل
Backend: Node.js + Express + Prisma + PostgreSQL.
Frontend: Flutter Web/Android.

### Local API
`cd backend && npm install && npx prisma generate && npx prisma db push && npm run seed && npm run dev`

### Flutter
`cd frontend && flutter pub get && flutter run --dart-define=API_URL=http://localhost:4000/api`

## Render
الملف `render.yaml` ينشئ PostgreSQL وخدمة API. اضبط `API_URL` عند بناء Flutter ليشير إلى رابط الخدمة المنشورة.

> هذه الحزمة مصممة للنشر، لكن لا يمكن اعتبار AAB/Render deployment منفذاً فعلياً داخل بيئة العمل هذه لعدم توفر Flutter/npm package download أثناء الإنشاء.
